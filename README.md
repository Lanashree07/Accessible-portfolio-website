# Accessible-portfolio-website
Accessible Personal Portfolio Website built using Semantic HTML5, CSS3, ARIA accessibility standards, and SEO best practices. Features a responsive multi-page design, keyboard-accessible navigation, and WCAG-compliant contact form for an inclusive user experience.🚀

## Project Overview
This project is a multi-page personal portfolio website built using Semantic HTML5 and Accessibility (WCAG) best practices. The website demonstrates the use of modern semantic elements, SEO-friendly metadata, ARIA attributes, and an accessible contact form to create a user-friendly and inclusive web experience.

## Features
- Semantic HTML5 structure
- Accessibility-focused design

- SEO-optimized meta tags
